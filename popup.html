Set BFI IMAX Ticket Alert

Be the first to book the moment tickets become available

Disclaimer: this is an independent, unofficial tool for film enthusiasts - not affiliated with or endorsed by the BFI. It only helps you catch sold-out slots the moment they reopen for popular films; all booking and payment always happens on BFI's own website.

Available screenings: tap an open screening to go straight to BFI's own website and finish booking there - this extension never books, holds, or pays for a ticket itself, it just gets you to the right page instantly.

Notify me for all screenings: tap this to get a BFI IMAX ticket alert the moment ANY screening of the shown film opens up. The dropdown alone doesn't do this - it just decides which film you're looking at.

Notify me for specific times only: instead of the button above, tap 🔕 next to one or more sold-out times below. Alerts then switch to just those times - tap 🔔 to drop one, or the link above to clear them all.

Desktop notification: a notification and a red badge on the toolbar icon fire automatically the moment a sold-out slot opens up - even if this popup is closed. No setup needed.

Films: the movie list is re-checked against BFI's own site every time you open it, so new titles should show up automatically. That said, it depends on BFI's listing pages keeping the same format, so we can't guarantee every new release is caught the moment it's announced.

My movie alerts: see every film and specific time you're currently set to be notified about, all in one place - tap it in the footer below.
